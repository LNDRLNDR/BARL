# BARL: Broadcast Assistant for Rocket League

BARL is a free Rocket League broadcasting overlay. It adds an automated series score tracker, real-time team boost meters, and customizable team names and logos to any stream. It runs while you spectate, play, or watch replays.

**[View the live page](https://lndrlndr.github.io/BARL/)** · [French version](https://lndrlndr.github.io/BARL/index_fr.html) · [Download BARL](https://lndrlndr.github.io/BARL_App/)

## Features

- Automated series score tracker for any best-of format
- Real-time team boost meters and per-player boost boxes
- Custom team names and logos through an in-app Control Panel
- Works in spectator mode, while playing, and during replays
- Plugs into Rocket League and OBS through a launcher download
- Premium plan adds community overlay designs and full custom design editing
